    Chapter 11. 변화를 한눈에 — 선그래프와 원그래프 만들기¶

    🎯 이 장의 학습 목표¶

    • 이 장을 마치면 시간의 흐름에 따른 변화를 선그래프로 표현할 수 있습니다.
    • 이 장을 마치면 전체 중 각 항목의 비율을 원그래프로 표현할 수 있습니다.
    • 이 장을 마치면 같은 데이터를 여러 그래프로 자유롭게 전환할 수 있습니다.
    • 예상 학습 시간: 약 40분

    📚 미리 알아야 할 것¶

    • 지난 장에서 배운 막대그래프 만들기 (데이터 선택 → 삽입 → 차트)
    • 스프레드시트에 데이터를 입력하는 방법

    📚 핵심 개념¶

    개념 1: 선그래프 — "데이터의 여행 경로"¶

    선그래프는 마치 등산 지도의 고도 곡선과 같아요. 산의 높낮이가 선으로 연결되어 오르막과 내리막을 한눈에 보여주듯, 선그래프는 시간의 흐름에 따라 값이 어떻게 변해왔는지를 선 하나로 보여줍니다.

    정확한 정의: 선그래프는 시간 순서대로 데이터 점을 찍고, 그 점들을 선으로 연결한 그래프예요.

    언제 쓸까요? - 연도별 기온 변화 - 월별 판매량 추이 - 시간별 주가 변동

    💡 핵심 포인트! 선그래프는 "변화의 흐름"을 보고 싶을 때 쓰는 그래프예요. 값이 오르고 있는지, 내리고 있는지 추세를 파악하기 딱 좋아요!

    개념 2: 원그래프 — "피자 한 판 나누기"¶

    원그래프는 마치 피자를 나눠 먹는 것과 같아요. 피자 한 판(전체 = 100%)을 조각 크기로 잘라서 누가 얼마나 차지하는지 보여주는 거예요.

    정확한 정의: 원그래프는 전체를 100%로 보고, 각 항목이 차지하는 비율을 부채꼴 모양으로 나타낸 그래프예요.

    언제 쓸까요? - 설문 응답 비율 (찬성 60%, 반대 40%) - 예산 분배 현황 - 시장 점유율 비교

    graph LR A[데이터 유형] --> B{무엇을 보고 싶은가?} B --> C[시간에 따른 변화] --> D[선그래프 📈] B --> E[전체 중 비율] --> F[원그래프 🥧] B --> G[항목 간 크기 비교] --> H[막대그래프 📊]

    💡 잠깐! 두 개념이 헷갈려도 괜찮아요! 실습하면서 자연스럽게 익혀지게 됩니다. 함께 만들어봐요 😊

    🔨 따라하기¶

    실습 1: 선그래프 만들기 (연도별 기온 변화)¶

    Step 1: 데이터 입력하기¶

    구글 스프레드시트를 열고, 아래 데이터를 A1부터 차례로 입력하세요.

    A열 (연도): 연도, 2019, 2020, 2021, 2022, 2023 B열 (평균기온): 평균기온(℃), 12.8, 13.1, 12.5, 13.6, 14.2

    ✅ 체크포인트: A1:B6 범위에 연도와 기온 데이터가 채워져 있어야 해요!

    Step 2: 선그래프 삽입하기¶

    1. 데이터 범위 A1:B6 을 마우스로 드래그해서 선택하세요.
    2. 상단 메뉴에서 삽입 → 차트 를 클릭하세요.
    3. 오른쪽에 차트 편집기가 열리면, 차트 유형 드롭다운을 클릭하세요.
    4. 목록에서 꺾은선 차트(선그래프) 를 선택하세요.
    5. 차트가 바뀌는 것을 확인하세요! 📈

    Step 3: 차트 유형 전환해보기¶

    같은 데이터가 그래프 종류에 따라 얼마나 다르게 보이는지 직접 경험해보세요!

    차트를 더블클릭해서 편집기를 열고, 차트 유형을 클릭할 때마다 바꿔보세요.

    • 막대그래프 → 각 연도 값을 막대로 비교
    • 선그래프 → 연도별 변화 흐름을 선으로 표현
    • 원그래프 → 각 연도 기온의 비율로 표현 (이 경우는 어색해 보일 거예요!)

    💬 "어? 원그래프로 바꾸면 이상해 보이죠?" — 맞아요! 이처럼 데이터 성격에 맞는 그래프를 선택하는 게 중요해요.

    실습 2: 원그래프 만들기 (설문 응답 비율)¶

    Step 1: 새 시트에 데이터 입력하기¶

    새 시트를 만들고 (하단의 + 버튼 클릭), 아래 데이터를 입력하세요.

    A열: 항목 / 매우 좋음 / 좋음 / 보통 / 싫음 B열: 응답수 / 40 / 30 / 20 / 10

    # 새 시트에 설문 데이터 입력
sheet2 = client.open("내 데이터").add_worksheet(title="설문결과", rows=10, cols=5)

survey_data = [
    ["항목", "응답수"],
    ["매우 좋음", 40],
    ["좋음", 30],
    ["보통", 20],
    ["싫음", 10],
]

sheet2.update("A1", survey_data)
print("설문 데이터 입력 완료! ✅")

    실행 결과: 

    설문 데이터 입력 완료! ✅

    Step 2: 원그래프 삽입하기¶

    1. A1:B5 범위를 선택하세요.
    2. 삽입 → 차트 클릭!
    3. 차트 편집기에서 차트 유형 → 원형 차트 선택
    4. 피자 조각처럼 나뉜 예쁜 원그래프 완성! 🥧

    ✅ 체크포인트: 원그래프에 "매우 좋음", "좋음", "보통", "싫음" 4가지 색 조각이 보여야 해요!

    📝 전체 코드¶

    import gspread
from google.oauth2.service_account import Credentials

# 인증 설정
scope = ["https://spreadsheets.google.com/feeds",
         "https://www.googleapis.com/auth/drive"]
creds = Credentials.from_service_account_file("credentials.json", scopes=scope)
client = gspread.authorize(creds)

# 스프레드시트 열기
spreadsheet = client.open("내 데이터")

# --- 선그래프용 데이터 (시트1) ---
sheet1 = spreadsheet.sheet1
line_data = [
    ["연도", "평균기온(℃)"],
    [2019, 12.8],
    [2020, 13.1],
    [2021, 12.5],
    [2022, 13.6],
    [2023, 14.2],
]
sheet1.update("A1", line_data)
print("선그래프 데이터 입력 완료! 📈")

# --- 원그래프용 데이터 (시트2) ---
sheet2 = spreadsheet.add_worksheet(title="설문결과", rows=10, cols=5)
pie_data = [
    ["항목", "응답수"],
    ["매우 좋음", 40],
    ["좋음", 30],
    ["보통", 20],
    ["싫음", 10],
]
sheet2.update("A1", pie_data)
print("원그래프 데이터 입력 완료! 🥧")

    ⚠️ 자주 하는 실수¶

    • 실수 1: 원그래프를 만들었는데 조각이 하나만 나와요!
    • 왜 이런 일이 생기나요? 데이터 범위를 헤더 없이 숫자만 선택했기 때문이에요.

    • 이렇게 해결해요: 항목 이름(A열)과 숫자(B열)를 함께 선택하세요.

    • 실수 2: 선그래프인데 선이 아니라 점만 찍혀 있어요!

    • 왜 이런 일이 생기나요? 차트 유형 중 "분산형 차트"를 선택했기 때문이에요.
    • 이렇게 해결해요: 차트 편집기에서 꺾은선 차트로 다시 선택하세요.

    📌 이 장의 핵심 정리¶

    • ✅ 선그래프: 시간 흐름에 따른 변화를 볼 때 사용 (연도별, 월별 추이)
    • ✅ 원그래프: 전체 대비 각 항목의 비율을 볼 때 사용 (설문, 점유율)
    • ✅ 차트 유형 전환: 차트 편집기 → 차트 유형 클릭으로 자유롭게 변환 가능
    • ✅ 데이터 성격에 맞는 그래프를 선택하는 것이 핵심!

    🤔 스스로 점검해 봐요¶

    • 선그래프와 원그래프를 각각 언제 쓰는지 설명할 수 있나요?
    • 차트 편집기에서 그래프 종류를 바꾸는 방법을 알고 있나요?
    • 내 프로젝트 데이터에는 어떤 그래프가 더 어울릴지 생각해봤나요?
    정답 확인 **선그래프 vs 원그래프** 선그래프는 "시간에 따른 변화(추이)"를 볼 때, 원그래프는 "전체 중 각 항목의 비율"을 볼 때 사용해요. **차트 유형 변경 방법** 차트를 더블클릭 → 오른쪽 차트 편집기 → "차트 유형" 드롭다운 클릭 → 원하는 차트 선택!

    Chapter 12. 관계를 발견하는 그래프 — 산점도 만들기¶

    🎯 이 장의 학습 목표¶

    • 두 변수 사이의 관계를 산점도로 시각화할 수 있습니다
    • 양의 상관, 음의 상관, 상관 없음 패턴을 구분할 수 있습니다
    • 추세선을 추가하여 데이터의 전반적 경향을 파악할 수 있습니다
    • 예상 학습 시간: 약 30분

    📚 미리 알아야 할 것¶

    • 지난 장에서 배운 막대 그래프와 꺾은선 그래프 개념
    • 구글 스프레드시트에서 차트 삽입하는 기본 방법

    📚 핵심 개념¶

    개념: 산점도 (Scatter Plot)¶

    비유로 시작: 산점도는 마치 지도에 핀을 꽂는 것과 같아요.

    서울 지도에 "맛집 위치"를 핀으로 표시하듯이, 산점도는 두 가지 정보를 가진 데이터를 좌표 위에 점으로 찍어서 표현합니다. X축(가로)에 하나의 정보, Y축(세로)에 또 다른 정보를 놓고, 둘이 만나는 자리에 점을 찍는 거예요.

    정확한 정의: 산점도는 두 변수의 관계를 점의 분포로 나타내는 그래프입니다.

    예시로 확인: - X축: 하루 운동 시간(분) - Y축: 수면 만족도(10점 만점) - 운동을 30분 하고 만족도가 7점이면 → (30, 7) 위치에 점 하나!

    점이 여러 개 모이면 패턴이 보이기 시작해요. 이 패턴이 바로 두 변수 사이의 상관관계입니다.

    세 가지 패턴 한눈에 보기¶

    graph LR A["점들이 우상향 📈<br/>→ 양의 상관<br/>하나가 늘면 다른 것도 증가"] B["점들이 우하향 📉<br/>→ 음의 상관<br/>하나가 늘면 다른 것은 감소"] C["점들이 흩어짐 🌀<br/>→ 상관 없음<br/>규칙적 패턴 없음"]

    💡 잠깐! 세 가지 패턴이 헷갈려도 괜찮아요. 실습하면서 눈으로 직접 보면 금방 감이 잡혀요!

    🔧 직접 해봐요¶

    실습: 구글 스프레드시트로 산점도 만들기¶

    목표: 운동 시간과 수면 만족도 데이터로 산점도 완성하기
    준비물: 구글 계정, 구글 스프레드시트

    Step 1: 데이터 입력하기¶

    새 스프레드시트를 열고 아래 데이터를 입력하세요.

    A열 (운동시간_분): 10, 20, 30, 45, 60, 75, 90, 15, 50, 80
    B열 (수면만족도): 4, 5, 6, 6, 8, 8, 9, 4, 7, 9

    1행은 제목(헤더)으로 입력하고, 2행부터 숫자를 넣으세요.

    ✅ 체크포인트: A1셀에 "운동시간_분", B1셀에 "수면만족도"가 보여야 해요!

    Step 2: 차트 삽입하기¶

    따라하기:

    1. A1부터 B11까지 드래그해서 전체 선택
    2. 상단 메뉴 [삽입] → [차트] 클릭
    3. 오른쪽에 차트 편집기가 열리면 차트 유형에서 "산점도" 선택
    4. X축에 "운동시간_분", Y축에 "수면만족도"가 자동으로 들어가는지 확인

    ✅ 체크포인트: 점들이 왼쪽 아래에서 오른쪽 위 방향으로 올라가는 모양이 보여야 해요!

    Step 3: 추세선 추가하기¶

    추세선은 점들의 전체적인 흐름을 한 줄로 요약해주는 선이에요.

    따라하기:

    1. 차트를 더블클릭해서 편집 모드 진입
    2. 오른쪽 편집기에서 [사용자 지정] 탭 클릭
    3. [계열] 항목을 펼치고 "추세선" 체크박스 활성화
    4. 추세선 유형은 "선형" 선택

    ✅ 체크포인트: 점들 사이를 가로지르는 대각선이 생겼다면 성공이에요! 🎉

    ⚠️ 자주 하는 실수¶

    실수 1: X축과 Y축이 반대로 들어갔어요! - 왜 이런 일이 생기나요? 데이터 선택 순서나 스프레드시트가 자동으로 배치를 결정해서 뒤바뀔 수 있어요. - 이렇게 해결해요: 차트 편집기 [설정] 탭에서 X축과 Y축 항목을 직접 바꿔주세요.

    실수 2: 산점도가 안 보이고 막대 그래프가 나와요! - 이렇게 해결해요: 차트 편집기 상단의 "차트 유형"을 클릭하고 목록에서 "산점도"를 찾아 다시 선택하세요.

    📌 이 장의 핵심 정리¶

    • ✅ 산점도는 두 변수의 관계를 점으로 표현한 그래프입니다
    • ✅ 점이 우상향하면 양의 상관, 우하향하면 음의 상관, 흩어지면 상관 없음입니다
    • ✅ 추세선을 추가하면 전체적인 흐름을 한눈에 파악할 수 있습니다

    🤔 스스로 점검해 봐요¶

    • "공부 시간이 늘수록 성적이 오른다"는 어떤 상관관계인지 말할 수 있나요?
    • 구글 스프레드시트에서 산점도를 직접 만들 수 있나요?
    • 추세선이 오른쪽 위를 향하면 어떤 의미인지 설명할 수 있나요?
    정답 확인 **Q1**: 양의 상관관계입니다. 공부 시간(X)이 늘수록 성적(Y)도 올라가므로 점들이 우상향합니다. **Q2**: 데이터 선택 → 삽입 → 차트 → 차트 유형에서 "산점도" 선택 순서로 만들 수 있어요. **Q3**: 추세선이 오른쪽 위를 향한다면 두 변수가 양의 상관관계를 가진다는 뜻이에요. X가 커질수록 Y도 커지는 경향이 있다는 의미입니다.

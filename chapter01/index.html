    Chapter 01. 데이터로 세상을 읽는다고? — 왜 데이터 분석을 배워야 할까¶

    🎯 이 장의 학습 목표¶

    • 일상생활에서 데이터가 활용되는 사례를 3가지 이상 설명할 수 있습니다.
    • 데이터 분석이 문제 해결에 도움이 되는 이유를 자신의 말로 표현할 수 있습니다.
    • 이 학습지의 전체 학습 흐름(6단계)을 파악할 수 있습니다.

    ⏱️ 예상 학습 시간: 약 30분

    📚 핵심 개념¶

    개념: 데이터 분석이란 무엇일까요?¶

    비유로 시작해 볼게요.

    데이터 분석은 마치 탐정이 단서를 모아 사건을 해결하는 것과 같아요.

    탐정은 발자국, 목격자 진술, CCTV 영상 같은 단서(= 데이터)를 모으고, 그것들을 연결해서(= 분석) 범인을 찾아내죠(= 결론). 데이터 분석도 똑같아요. 숫자와 기록을 모아서, 그 안에 숨겨진 의미를 찾아내는 과정이에요.

    정확한 정의

    데이터 분석이란, 수집된 정보(데이터)를 정리하고 살펴봐서 의미 있는 결론을 이끌어내는 과정이에요.

    예시로 확인해 볼게요!

    우리 주변에 이미 데이터 분석이 가득해요. 낯설게 느껴지지 않아도 돼요 😊

    • 🎬 유튜브 추천 알고리즘: 내가 본 영상 기록을 분석해서 "이 영상 좋아하실 것 같아요"를 추천해요.
    • 🍱 학교 급식 만족도 조사: 설문 결과를 분석해서 인기 없는 메뉴를 바꾸거나 인기 메뉴를 더 자주 제공해요.
    • 🌦️ 날씨 예보: 기온, 습도, 기압 데이터를 분석해서 "내일 비 올 확률 80%"를 알려줘요.

    💡 잠깐! 어때요? 우리 이미 매일 데이터 분석의 결과를 누리고 있었죠? 데이터 분석은 특별한 사람만 하는 게 아니에요. 이 학습지를 마치면 여러분도 할 수 있어요!

    🔨 따라하기 — 데이터적으로 생각해 보기¶

    이번 실습은 코드가 없어요! 대신 생각하는 연습을 해볼게요.

    Step 1: 문제 상황 읽기¶

    다음 상황을 읽어보세요.

    상황: 관양고 학생들이 점심시간에 매점에 너무 많이 몰려서 줄이 길어요. 어떻게 하면 줄을 줄일 수 있을까요?

    Step 2: 어떤 데이터가 필요할지 생각하기¶

    이 문제를 해결하려면 어떤 정보(데이터)가 있으면 좋을까요? 빈칸에 직접 적어보세요!

    📝 내가 필요하다고 생각하는 데이터:

1. ___________________________
2. ___________________________
3. ___________________________

    Step 3: 예시 답과 비교해 보기¶

    💡 예시 답:

1. 요일별·시간대별 매점 방문 인원 수
2. 가장 많이 팔리는 인기 상품 목록
3. 학생들이 매점에서 머무는 평균 시간

    ✅ 체크포인트: 내 답이 예시와 꼭 같지 않아도 괜찮아요! "문제를 해결하는 데 필요한 정보가 뭘까?" 라고 생각했다면 이미 데이터적 사고를 시작한 거예요. 👏

    🗺️ 이 학습지의 전체 여정¶

    이 학습지는 총 6단계로 진행돼요. 각 단계를 마칠 때마다 발표 자료의 한 페이지가 완성된답니다!

    flowchart LR A["1️⃣ 문제 정의\n무엇을 알고 싶지?"] --> B["2️⃣ 데이터 수집\n정보를 모으자"] B --> C["3️⃣ 전처리\n데이터를 정리하자"] C --> D["4️⃣ 시각화\n그래프로 보자"] D --> E["5️⃣ 분석 해석\n의미를 찾자"] E --> F["6️⃣ 발표\n세상에 알리자!"]

    지금 여러분은 1단계의 시작점에 서 있어요. 천천히, 한 걸음씩 나아가면 돼요 🚶

    ⚠️ 주의할 점¶

    • 데이터가 많다고 좋은 게 아니에요! 문제와 관계없는 데이터는 오히려 분석을 복잡하게 만들어요. 중요한 건 "이 문제에 꼭 필요한 데이터인가?"를 따져보는 거예요.
    • 데이터는 사실이지만, 해석은 사람이 해요. 같은 데이터를 봐도 다른 결론이 나올 수 있어요. 그래서 비판적으로 생각하는 연습이 중요해요.

    ✅ 점검하기¶

    1. 일상에서 데이터 분석이 활용되는 예시를 2가지 말해보세요.
    정답 확인 유튜브 영상 추천, 날씨 예보, 급식 메뉴 결정, 쇼핑몰 상품 추천 등 다양한 답이 가능해요. 여러분이 떠올린 예시도 충분히 맞을 수 있어요!
    1. 데이터 분석의 6단계 흐름을 순서대로 말해보세요.
    정답 확인 문제 정의 → 데이터 수집 → 전처리 → 시각화 → 분석 해석 → 발표

    📌 이 장의 핵심 정리¶

    • ✅ 데이터 분석은 정보를 모아 의미를 찾아내는 과정이에요.
    • ✅ 유튜브 추천, 날씨 예보, 급식 조사 등 우리 주변은 이미 데이터 분석으로 가득해요.
    • ✅ 이 학습지는 문제 정의 → 수집 → 전처리 → 시각화 → 해석 → 발표 6단계로 진행돼요.

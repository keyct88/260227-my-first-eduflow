    Chapter 03. 궁금한 것을 찾아라 — 브레인스토밍으로 주제 탐색하기¶

    🎯 이 장의 학습 목표¶

    • 이 장을 마치면 관심사에서 분석 주제를 5가지 이상 떠올릴 수 있어요
    • 이 장을 마치면 데이터로 탐구 가능한 주제와 그렇지 않은 주제를 구분할 수 있어요
    • 예상 학습 시간: 약 30분

    📚 미리 알아야 할 것¶

    • (Chapter 01) 데이터 분석이 어떤 과정인지 큰 그림을 알고 있어요
    • (Chapter 02) 좋은 질문이 좋은 분석의 시작이라는 걸 배웠어요

    📚 핵심 개념¶

    개념: 브레인스토밍(Brainstorming)¶

    비유로 시작: 브레인스토밍은 마치 냉장고 문을 활짝 열고 있는 재료를 전부 꺼내 놓는 것과 같아요. 좋은 재료인지 나쁜 재료인지 아직 따지지 않아요. 일단 다 꺼내는 거예요!

    정확한 정의: 브레인스토밍이란 좋고 나쁨을 판단하지 않고 떠오르는 아이디어를 최대한 많이 쏟아내는 방법이에요. '이게 말이 되나?' 고민하지 말고 일단 적는 것이 핵심이에요.

    예시로 확인: '학교생활'이라는 키워드 하나로 아이디어를 쏟아내 봤어요.

    mindmap root((학교생활)) 급식 좋아하는 메뉴 순위 잔반 양 변화 요일별 칼로리 수면 수면 시간과 성적 관계 학년별 평균 수면 시간 주중 vs 주말 수면 차이 통학 통학 시간과 피로도 교통수단별 지각 횟수 스마트폰 하루 평균 사용 시간 앱별 사용 비율

    이렇게 하나의 주제에서 여러 방향으로 아이디어가 펼쳐져요! ✨

    💡 잠깐! 아직 "이게 분석이 될까?" 걱정하지 않아도 돼요.
    지금은 그냥 많이 떠올리는 것이 목표예요. 판단은 나중에 해요!

    🔧 직접 해봐요¶

    실습: 나만의 주제 브레인스토밍¶

    목표: 내 관심사에서 분석 주제 후보를 5개 이상 만들기
    준비물: 종이와 펜 (또는 메모장 앱)

    따라하기

    Step 1: 아래 카테고리 중 2가지 이상 골라요.

    • 🏫 학교생활 — 급식, 수업, 시험, 동아리
    • 🌍 사회·환경 — 날씨, 미세먼지, 에너지
    • 🎮 취미·관심사 — 게임, 음악, 스포츠, 유튜브
    • 💼 진로·직업 — 관심 직업, 관련 학과, 취업률
    • 🏙️ 우리 동네 — 교통, 범죄, 편의시설

    Step 2: 고른 카테고리마다 3분 동안 떠오르는 것을 모두 적어요.
    이때 딱 하나 규칙만 지켜요: 절대 지우지 않기!

    Step 3: 적은 것들 중에서 가장 궁금한 것에 ⭐ 표시해요.

    ✅ 체크포인트: 여기까지 마쳤다면 종이에 아이디어가 최소 5개 이상 있어야 해요!

    🔍 좋은 주제 vs 어려운 주제 구분하기¶

    아이디어를 다 모았으면 이제 데이터로 탐구할 수 있는지 확인할 차례예요.

    아래 체크리스트를 각 아이디어에 적용해 보세요.

    ✅ 데이터 탐구 가능 체크리스트 - 데이터를 구할 수 있나요? (인터넷 검색, 직접 측정, 설문 등) - 숫자로 표현할 수 있나요? (개수, 비율, 점수, 시간 등) - 구글 스프레드시트로 정리할 수 있나요? (표로 만들 수 있다면 OK!)

    아래 예시로 감을 잡아봐요.

    flowchart LR A["💤 수면 시간과 성적 관계"] --> B{"체크리스트\n통과?"} B -->|"✅ 숫자로 측정 가능\n✅ 설문으로 수집 가능"| C["👍 좋은 주제"] D["😔 학교생활이 힘든 이유"] --> E{"체크리스트\n통과?"} E -->|"❌ 감정이라 수치화 어려움\n❌ 분석 방향이 모호함"| F["🔄 다듬기 필요"]

    '학교생활이 힘든 이유'는 나쁜 주제가 아니에요!
    다만 "힘들다고 느끼는 이유를 설문으로 항목화하고 비율을 분석한다"처럼 조금 더 구체화하면 좋은 주제가 돼요. 😊

    💡 선배들이 실제로 선택했던 주제 예시 - "고등학생 수면 시간과 성적의 관계" — 학급 설문으로 데이터 수집 - "우리 동네 미세먼지 월별 변화 추이" — 에어코리아 공공 데이터 활용 - "유튜브 구독자 수와 영상 업로드 빈도의 상관관계" — 직접 채널 데이터 수집

    ⚠️ 자주 하는 실수¶

    • 실수 1: "이런 게 주제가 될까?" 싶어서 처음부터 아이디어를 걸러내요.
    • 왜 이런 일이 생기나요? 완벽한 주제를 처음부터 찾으려 하기 때문이에요.

    • 이렇게 해결해요: 브레인스토밍 단계에서는 무조건 많이! 판단은 Step 3에서 해요.

    • 실수 2: 주제가 너무 커요. (예: "기후 변화 분석")

    • 왜 이런 일이 생기나요? 관심 주제를 그대로 쓰기 때문이에요.
    • 이렇게 해결해요: "우리 지역 여름 평균 기온 10년 변화"처럼 범위를 좁혀요.

    📌 이 장의 핵심 정리¶

    • ✅ 브레인스토밍은 판단 없이 아이디어를 최대한 많이 쏟아내는 방법이에요
    • ✅ 관심사 → 세부 주제 → 데이터 가능 여부 순서로 주제를 좁혀가요
    • ✅ 숫자로 측정 가능하고, 데이터를 구할 수 있는 주제가 좋은 분석 주제예요

    🤔 스스로 점검해 봐요¶

    • 브레인스토밍이 무엇인지 한 문장으로 설명할 수 있나요?
    • 내 관심사에서 주제 후보를 5개 이상 만들었나요?
    • 각 주제에 체크리스트를 적용해 실현 가능성을 확인했나요?
    ✅ 점검 기준 확인 **브레인스토밍**: "판단하지 않고 아이디어를 많이 내는 방법"이라고 설명할 수 있으면 OK! **좋은 주제 기준**: 숫자로 표현 가능 + 데이터 수집 가능 + 스프레드시트로 정리 가능 — 이 세 가지를 말할 수 있으면 완벽해요!

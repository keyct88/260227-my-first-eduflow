    Chapter 06. 직접 해보는 데이터 수집 — 구글 스프레드시트에 데이터 정리하기¶

    🎯 이 장의 학습 목표¶

    • 수집한 데이터를 구글 스프레드시트에 올바른 형태로 입력할 수 있습니다.
    • 행과 열의 의미를 이해하고, 데이터를 표 형태로 구조화할 수 있습니다.
    • 자신의 프로젝트 데이터를 직접 스프레드시트에 정리할 수 있습니다.

    예상 학습 시간: 약 40분

    📚 미리 알아야 할 것¶

    지난 챕터에서 우리는 데이터를 어디서, 어떻게 수집하는지 배웠어요. 설문 조사를 만들거나 공공데이터를 찾아보셨죠? 이번 챕터에서는 그렇게 모은 데이터를 실제로 정리하는 방법을 배울 거예요.

    💡 잠깐! 구글 계정이 필요해요. 아직 없다면 지금 바로 만들어 두세요. 구글 스프레드시트는 무료로 사용할 수 있어요!

    📚 핵심 개념¶

    개념 1: 스프레드시트의 행과 열¶

    스프레드시트는 마치 모눈종이와 같아요. 가로줄과 세로줄이 격자처럼 나뉘어져 있고, 각 칸에 데이터를 하나씩 넣을 수 있어요.

    • 열(Column): 세로 방향 칸들의 묶음. 알파벳 A, B, C...로 표시돼요. → 같은 종류의 정보가 들어가요.
    • 행(Row): 가로 방향 칸들의 묶음. 숫자 1, 2, 3...으로 표시돼요. → 하나의 관찰 결과(한 사람, 한 응답)가 들어가요.
    • 셀(Cell): 행과 열이 만나는 한 칸. A1, B3 이런 식으로 불러요.
    graph TD A["스프레드시트"] --> B["열(Column): 항목 이름\n예) 이름, 나이, 점수"] A --> C["행(Row): 한 건의 데이터\n예) 홍길동, 16, 85"] B --> D["셀: 열과 행이 만나는 곳\n예) A1 = '이름'"] C --> D

    개념 2: 데이터 정리의 황금 규칙 2가지¶

    데이터를 스프레드시트에 넣을 때 꼭 지켜야 할 규칙이 두 가지 있어요. 이걸 지키지 않으면 나중에 분석할 때 오류가 생겨요!

    🥇 규칙 1 — 첫 번째 행은 항목 이름(헤더)

    1행에는 각 열이 무엇을 뜻하는지 이름을 적어요. 예를 들어 이름, 나이, 좋아하는 과목 처럼요. 이 행을 헤더(Header) 라고 불러요.

    🥈 규칙 2 — 한 행에는 하나의 데이터

    한 사람의 응답은 한 줄(행)에 모두 담아요. 절대 한 칸에 여러 정보를 섞어 넣지 않아요!

    💡 잠깐! 이 두 가지 규칙만 지켜도 나중에 파이썬으로 분석할 때 훨씬 편해져요. 지금 습관을 잘 들여놓으면 나중에 분명히 "아, 잘했다!" 싶을 거예요 😊

    🔧 직접 해봐요¶

    목표: 예시 데이터를 스프레드시트에 올바르게 입력하고, 내 프로젝트 데이터까지 정리해봐요.

    준비물: 구글 계정, 인터넷 연결

    Step 1: 구글 스프레드시트 열기¶

    따라하기:

    1. 크롬 브라우저를 열고 주소창에 sheets.new 를 입력한 후 Enter를 눌러요.
    2. 구글 계정으로 자동 로그인되면서 빈 스프레드시트가 열려요.
    3. 왼쪽 위 "제목 없는 스프레드시트"를 클릭해서 이름을 바꿔요. → 예: 내 프로젝트 데이터

    ✅ 체크포인트: 빈 격자 화면이 보이고, 위쪽에 A, B, C... 알파벳이, 왼쪽에 1, 2, 3... 숫자가 보이면 성공이에요!

    Step 2: 헤더(항목 이름) 입력하기¶

    따라하기:

    1. A1 셀을 클릭해요 (가장 왼쪽 위 칸).
    2. 아래 예시를 보고 1행에 헤더를 입력해요. Tab 키를 누르면 옆 칸으로 이동해요.

    예시 — 반 친구들 수면 시간 조사 데이터

    • A1: 번호
    • B1: 성별
    • C1: 수면시간(시간)
    • D1: 피로도(1~5점)
    • E1: 스마트폰 사용시간(시간)

    ✅ 체크포인트: 1행 전체가 굵게 보이면 더 좋아요. 헤더 행을 선택하고 굵게(Ctrl+B) 처리해두면 나중에 구분하기 쉬워요!

    Step 3: 데이터 입력하기¶

    따라하기:

    1. A2 셀부터 아래로 내려가며 데이터를 입력해요. Enter 키를 누르면 아래 칸으로 이동해요.
    2. 아래 샘플 데이터를 그대로 입력해봐요.

    입력할 샘플 데이터 (5건)

    • 2행: 1 / 남 / 6 / 3 / 2
    • 3행: 2 / 여 / 7.5 / 2 / 1.5
    • 4행: 3 / 남 / 5 / 4 / 3
    • 5행: 4 / 여 / 8 / 1 / 1
    • 6행: 5 / 남 / 6.5 / 3 / 2.5

    ✅ 체크포인트: 숫자 데이터(수면시간, 피로도 등)는 셀 안에서 오른쪽 정렬이 되어야 해요. 왼쪽 정렬이면 텍스트로 인식된 거예요. 숫자인데 왼쪽 정렬이라면 앞에 스페이스나 따옴표가 없는지 확인해봐요!

    Step 4: 내 프로젝트 데이터 입력하기¶

    따라하기:

    1. 아래 시트 탭(화면 맨 아래)에서 + 버튼을 눌러 새 시트를 추가해요.
    2. 시트 이름을 프로젝트데이터로 바꿔요 (탭을 더블클릭하면 이름 수정 가능).
    3. 내가 수집한 데이터(설문 결과 또는 공공데이터)를 Step 2~3과 똑같은 방식으로 입력해요.

    💡 잠깐! 공공데이터를 사용한다면 CSV 파일을 직접 가져올 수도 있어요. 파일 → 가져오기 → 업로드 메뉴를 이용해보세요. 훨씬 빠르답니다!

    ⚠️ 자주 하는 실수¶

    실수 1: 한 셀에 여러 정보 넣기

    • 예시: A2에 홍길동, 16세, 남자 라고 모두 입력하는 경우
    • 왜 문제가 될까요? 나중에 파이썬으로 분석할 때 이름, 나이, 성별을 따로따로 꺼낼 수가 없어요.
    • 해결법: 정보는 반드시 열을 나눠서 각각의 셀에 하나씩 입력하세요.

    실수 2: 숫자에 단위를 같이 쓰기

    • 예시: 6시간, 85점 처럼 단위를 숫자와 함께 입력하는 경우
    • 왜 문제가 될까요? 컴퓨터가 이걸 숫자가 아닌 텍스트로 인식해서 계산을 못해요.
    • 해결법: 셀에는 숫자만(6, 85) 입력하고, 단위는 헤더 이름에 써두세요. 예) 수면시간(시간)

    📌 이 장의 핵심 정리¶

    • ✅ 스프레드시트의 열은 항목(종류), 행은 하나의 데이터(한 건의 응답)예요.
    • ✅ 1행은 항상 헤더로 사용하고, 2행부터 실제 데이터를 입력해요.
    • ✅ 한 셀에는 하나의 정보만, 숫자 셀에는 숫자만 입력해요.

    🤔 스스로 점검해 봐요¶

    • 행과 열의 차이를 말로 설명할 수 있나요?
    • 헤더가 왜 필요한지 이유를 알고 있나요?
    • 내 프로젝트 데이터를 스프레드시트에 직접 입력해봤나요?

    ✅ 점검하기

    1. 스프레드시트에서 데이터의 '항목 이름'은 몇 번째 행에 넣어야 할까요?
    정답 확인첫 번째 행(1행)에 넣어야 해요. 이를 헤더(Header)라고 부르고, 이후 행부터 실제 데이터가 시작돼요.
    1. 수면 시간이 7시간 이라면 셀에 어떻게 입력해야 할까요?
    정답 확인">정답 확인셀에는 숫자 `7`만 입력하고, 단위는 헤더 이름에 `수면시간(시간)`처럼 표시해두면 돼요.

    🚀 다음 장 미리보기¶

    데이터 정리가 끝났다면 이제 본격적인 분석을 시작할 준비가 된 거예요! 다음 챕터에서는 정리한 스프레드시트 데이터를 파이썬으로 불러오는 방법을 배울 거예요. 파이썬이 우리 대신 데이터를 읽어주는 순간, 분석이 훨씬 빨라진답니다. 기대해도 좋아요! 🐍

    Chapter 13. 내 그래프 완성하기 — 시각화 중간 점검 및 다듬기¶

    🎯 이 장의 학습 목표¶

    • 이 장을 마치면 좋은 그래프의 조건을 스스로 점검할 수 있습니다
    • 이 장을 마치면 내 그래프의 부족한 점을 찾아 개선할 수 있습니다
    • 예상 학습 시간: 약 30분

    📚 미리 알아야 할 것¶

    이전 장들에서 배운 내용을 잠깐 떠올려 볼까요?

    • 막대그래프: 카테고리별 수치 비교
    • 꺾은선그래프: 시간에 따른 변화 추이
    • 산점도: 두 데이터 사이의 관계
    • 히스토그램: 데이터 분포 파악

    이번 장은 이 네 가지를 배운 후 "내 그래프가 제대로 만들어졌는지" 점검하는 시간이에요. 마치 시험 답안지를 제출하기 전에 한 번 더 검토하는 것처럼요! ✍️

    📚 핵심 개념¶

    개념: 좋은 그래프의 체크리스트¶

    💡 잠깐! 그래프를 만들었다고 끝이 아니에요.
    "보는 사람이 쉽게 이해할 수 있는가?"가 더 중요합니다!

    좋은 그래프는 마치 잘 쓴 표지판과 같아요. 도로 표지판에 목적지 이름도 없고, 거리도 없다면 아무리 크게 세워놔도 쓸모가 없겠죠? 그래프도 마찬가지예요.

    좋은 그래프가 갖춰야 할 5가지 조건:

    • ✅ 제목이 있다 — 이 그래프가 무엇을 보여주는지 한 문장으로
    • ✅ 축 레이블이 있다 — x축, y축이 각각 무엇을 나타내는지
    • ✅ 단위가 명시되어 있다 — (명), (원), (℃) 등
    • ✅ 색상이 구분하기 쉽다 — 색이 너무 비슷하거나 너무 현란하지 않게
    • ✅ 범례가 있다 — 여러 데이터가 있을 때 어떤 색이 무엇인지

    🔨 따라하기¶

    Step 1: 개선 전 그래프 vs 개선 후 그래프 비교¶

    아래 두 코드를 실행해서 차이를 직접 확인해 보세요!

    ❌ 개선 전 — 정보가 부족한 그래프:

    import matplotlib.pyplot as plt

subjects = ['수학', '영어', '과학', '국어']
scores = [85, 92, 78, 88]

plt.bar(subjects, scores)
plt.show()

    실행 결과: 

    제목 없음, 축 설명 없음, 단위 없음 — 뭘 보여주는 그래프인지 모름!

    Step 2: 체크리스트를 적용한 개선 후 그래프¶

    import matplotlib.pyplot as plt
plt.rcParams['font.family'] = 'Malgun Gothic'  # 한글 설정

subjects = ['수학', '영어', '과학', '국어']
scores = [85, 92, 78, 88]

# 색상으로 시각적 강조
colors = ['#4C72B0', '#DD8452', '#55A868', '#C44E52']

plt.figure(figsize=(8, 5))
plt.bar(subjects, scores, color=colors)

# ✅ 제목 추가
plt.title('2학년 1반 평균 과목별 점수', fontsize=15)

# ✅ 축 레이블 + 단위 추가
plt.xlabel('과목')
plt.ylabel('점수 (점)')

# ✅ y축 범위 조정 (차이가 더 잘 보이게)
plt.ylim(60, 100)

plt.tight_layout()
plt.show()

    실행 결과: 

    - 제목: "2학년 1반 평균 과목별 점수" 표시됨
- x축: 과목명 표시
- y축: 점수 (점) 표시
- 각 막대가 서로 다른 색으로 구분됨

    ✅ 체크포인트: 두 그래프를 비교했을 때, 개선 후 그래프가 훨씬 무슨 내용인지 바로 이해되시나요? 이게 바로 체크리스트의 힘이에요!

    Step 3: 내 그래프에 체크리스트 적용하기¶

    지금까지 만든 내 프로젝트 그래프를 열고, 아래 항목을 하나씩 확인해 보세요.

    # 아래 항목들이 내 코드에 있는지 확인하세요!

plt.title('여기에 그래프 제목을 쓰세요')   # 제목
plt.xlabel('x축이 나타내는 것 (단위)')     # x축 레이블
plt.ylabel('y축이 나타내는 것 (단위)')     # y축 레이블
plt.legend()                              # 범례 (여러 데이터일 때)
plt.tight_layout()                        # 레이아웃 자동 정리

    📝 전체 점검 코드¶

    내 그래프를 체크리스트 기준으로 완성하는 템플릿이에요. 복사해서 활용해 보세요!

    import matplotlib.pyplot as plt
plt.rcParams['font.family'] = 'Malgun Gothic'

# --- 여기에 내 데이터를 넣으세요 ---
x_data = ['항목1', '항목2', '항목3']
y_data = [10, 20, 30]
# -----------------------------------

plt.figure(figsize=(8, 5))
plt.bar(x_data, y_data, color='steelblue')  # 그래프 종류 변경 가능

# ✅ 체크리스트 5가지 적용
plt.title('그래프 제목을 여기에')          # 1. 제목
plt.xlabel('x축 이름 (단위)')             # 2. x축 레이블+단위
plt.ylabel('y축 이름 (단위)')             # 3. y축 레이블+단위
# 색상은 color 파라미터로 이미 적용       # 4. 색상
# 여러 데이터라면 plt.legend() 추가       # 5. 범례

plt.tight_layout()
plt.show()

    ⚠️ 자주 하는 실수¶

    • 실수 1: 제목은 달았는데 축 레이블을 빠뜨리는 경우
    • 왜 생기나요? 그래프가 그려지면 "다 됐다!"고 느끼기 때문이에요

    • 해결법: 코드를 쓸 때 plt.title, plt.xlabel, plt.ylabel 세 줄을 세트로 항상 함께 써요

    • 실수 2: 한글이 깨져서 □□□로 나오는 경우

    • 해결법: 코드 맨 위에 plt.rcParams['font.family'] = 'Malgun Gothic' 추가! (Mac은 'AppleGothic')

    ✅ 점검하기¶

    1. 좋은 그래프가 반드시 갖춰야 할 요소 3가지를 말해보세요.
    정답 확인 ① **제목** (무엇을 보여주는 그래프인지), ② **축 레이블과 단위** (x축/y축이 무엇인지), ③ **색상 구분 또는 범례** (데이터를 구별할 수 있도록). 이 세 가지가 없으면 보는 사람이 그래프를 이해하기 어려워요!
    1. plt.ylabel('점수 (점)')에서 (점) 을 붙이는 이유는 무엇인가요?
    정답 확인 **단위**를 명시하기 위해서예요. "점수"만 쓰면 100점 만점인지, 1000점 만점인지 모르잖아요. 단위가 있어야 데이터를 정확하게 해석할 수 있어요.

    📌 이 장의 핵심 정리¶

    • ✅ 좋은 그래프는 제목 / 축 레이블+단위 / 색상 구분 / 범례 를 갖춰야 해요
    • ✅ 그래프를 만든 후 5가지 체크리스트로 스스로 점검하는 습관이 중요해요
    • ✅ plt.tight_layout()은 레이아웃을 자동으로 정리해주는 유용한 한 줄이에요
